# IziÉkszer – Jewelry Experience

A static business website for IziÉkszer, a Hungarian jewelry and ear piercing service based in Esztergom.
The site is live at 
https://varhidibence.github.io/IziEkszer/
## Services featured

- **Ear Piercing at Home** – Mobile sterile capsule ear piercing using the Studex system
- **Ear Piercing at Events** – On-site piercing service for events and festivals
- **Jewelry Courier Webshop** – Gold, silver and medical-grade jewelry
- **Charm Bar Webshop** – Handcrafted custom charm jewelry
- **Charm Bar at Events** – Live charm bracelet assembly at events
- **Events** – Upcoming and past event listings

## Tech stack

- HTML5, CSS3, JavaScript (vanilla)
- Bootstrap 5.3
- Hosted on GitHub Pages

## Project structure

```
index.html        Main page
css/style.css     Custom styles
js/main.js        Event listings, lightbox, navigation logic
pics/             Images and icons
docs/             Project documentation
```
